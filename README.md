# Sukaina Tube

تطبيق أندرويد محلي (بدون إنترنت) يعرض فيديوهات الهاتف بواجهة تحاكي يوتيوب،
مخصّص للاستخدام العائلي الآمن للأطفال.

- **بدون إعلانات، بدون إنترنت، بدون رفع أي ملف.**
- يقرأ الفيديوهات من ذاكرة الهاتف عبر `MediaStore` ويعرض كل مجلد كـ«قناة».
- شاشة رئيسية + Shorts + الاشتراكات + المكتبة + شاشة مشاهدة بتحكم يشبه يوتيوب.
- أرقام مشاهدات وتواريخ واشتراكات «وهمية» ثابتة لكل فيديو لإيهام الطفل بأنه على يوتيوب.
- لوحة ولي أمر مخفية برمز PIN: اختيار المجلدات المعروضة، إخفاء Shorts/البحث/التعليقات،
  مسح السجل، وقفل الخروج من التطبيق.

## تنزيل التطبيق (بدون أدوات برمجة)

1. افتح تبويب **Actions** في هذا المستودع.
2. اختر آخر تشغيل ناجح لـ **Build APK**.
3. من قسم **Artifacts** نزّل `SukainaTube-debug-apk` واستخرج منه `SukainaTube-debug.apk`.
4. انقل الملف إلى هاتف أندرويد وثبّته (فعّل «تثبيت من مصادر غير معروفة»).

بدلاً من ذلك: كل وسم إصدار (`v1.0`) يُنشئ صفحة **Releases** تحتوي ملف APK جاهزاً.

## التشغيل من المصدر

```bash
./gradlew :app:assembleDebug
```

المتطلبات: JDK 17، Android SDK (platform 35، build-tools 35.0.0)، Gradle 8.12.

## صلاحيات التطبيق

| الصلاحية | السبب |
| --- | --- |
| `READ_MEDIA_VIDEO` (أندرويد 13+) | قراءة الفيديوهات |
| `READ_EXTERNAL_STORAGE` (حتى أندرويد 12) | قراءة الفيديوهات |
| `READ_MEDIA_VISUAL_USER_SELECTED` (أندرويد 14+) | دعم الوصول الجزئي للفيديوهات |

## الوصول إلى إعدادات ولي الأمر

- اضغط مطوّلاً على شعار التطبيق في الأعلى، **أو** اضغط ٥ مرات على صورة الحساب،
  **أو** زر الإعدادات في تبويب «المكتبة». أول مرة يُطلب إنشاء رمز من ٤ أرقام.

## ملاحظة

هذا المشروع غير مرتبط بـ YouTube ولا يمثلها. الشعار المستخدم هو شعار خاص بالتطبيق
(زر تشغيل أحمر) وليس العلامة التجارية الأصلية.
